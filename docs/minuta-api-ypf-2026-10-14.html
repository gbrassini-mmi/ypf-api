Qué muestra la referencia v1

Todas las rutas son GET, de solo lectura, en JSON, con fechas ISO 8601 en UTC. Cada request lleva un access token OAuth2 de Cognito (client_credentials, vigencia de 60 minutos).

  • /v1/equipmentEquipos asignados a YPF con servicio activo
  • /v1/equipment/{serial}Detalle del equipo y sus pozos activos
  • …/{serial}/live · /live/{pozo}Último valor de cada tópico, por equipo o por pozo
  • …/well/{pozo}/topics/{tópico}/historyHistórico paginado de un tópico
  • …/wells/{pozos}/sanding-eventsEventos de desarenado de uno o más pozos

El histórico y los desarenados devuelven solo los tramos del período en que el equipo estuvo contratado por YPF.

Confirmaciones sobre el pliego

Cómo cubre la API dos puntos del pliego técnico. Pedimos que nos confirmen que están de acuerdo.

Variables expuestas

El pliego (p. 14) prevé la exposición de todas las variables. A pedido de YPF, esta API comparte solo el listado de variables que ustedes nos indiquen.

Eficiencia del desarenador

Les enviamos los totalizadores calculados por nosotros. La API también expone los datos de origen, para que puedan reconstruirlos si guardan la información de su lado.
